怎么用

第一次用

  • 连上公司 Wi-Fi，打开 http://192.168.31.145:8090。
  • 输入你的用户名（和研发平台一样，比如 h），点「进入」。在研发平台登录过的话会自动进来。

提问

  • 新人可在首页按开发、QA、产品或维运角色展开上手问题，点击问题会带入提问框；确认后再提交。角色选择只是导览，不改变账号权限。
  • 已有明确关键词时，可以先用首页的「搜索资料」查找已发布内容。
  • 在首页大框里用自己的话写问题，可以附截图（最多 3 张）。不用写得很专业。
  • 输入时下面如果出现「可能是你要找的」，先点开看看，也许已经有答案。
  • 点「提问」后会有几道选择题，点选就行；都不合适就在「其他」里写。也可以直接「跳过」。
  • 一般 1–3 分钟出答案，页面会自己刷新。

看答案

  • 上面是结论和大白话解释，看这部分就够了。
  • 「依据（给开发看）」里是代码出处，转给开发时直接发这个页面的链接。
  • 没看懂：写下哪里没懂，点「没懂，继续问」，会出新一版回答。
  • 答错了：写一句哪里不对，点「答错了」。
  • 所有问题和后续问答默认收入资料库，并保留每轮提问人、时间和回答。你也可以点「有用」反馈。
  • 在资料库打开别人提出的问题，点「回到这个问题继续提问」，即可在同一线程接着问。本轮作答结束后可提交下一轮。
  • 自动收录只是留档；标有「需审核」的回答仍不能视为已确认结论。

常见问题

  • 打不开？先确认连的是公司网络，在家打不开是正常的。
  • 一直「排队中」？右上角「作答离线」说明作答电脑没开，开机后会自动处理，题目不会丢。
  • 能让它改代码或提单吗？不能。它只回答「是什么、为什么、怎么用」；发现文案和实际不一致会给一份 bug 草稿，提不提你决定。
  • 每天能问几次？每人每天 20 个问题。

开发者：用 MCP 接入

Claude Code：

claude mcp add --transport http cardorder-kb http://192.168.31.145:8090/mcp/ --header "X-KB-Uid: 你的用户名"

Codex（~/.codex/config.toml）：

[mcp_servers.cardorder-kb] url = "http://192.168.31.145:8090/mcp/" http_headers = { "X-KB-Uid" = "你的用户名" }

工具：kb_onboarding / kb_search / kb_get / kb_ask / kb_status / kb_followup / kb_feedback / kb_publish。资料目录：/llms.txt。

新人上手：先调用 kb_onboarding（role 可选 dev / qa / product / ops；省略返回全部角色），再用 kb_search 查资料；需要作答时调用 kb_ask，将角色放入 audience、上手主题放入 page。上手清单是问题引导，不是已验证答案或权限授权。
